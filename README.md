# Aproximación cinemática de la interacción entre eyecciones de masa coronal homólogas
Compilado de códigos de simulación desarrollados a lo largo de la investigación en la búsqueda de umbrales de interacción para CMEs homólogas.

Se presentan dos carpetas, una con el código base utilizado para simular la cinemática, así como los mapas polares de velocidad y densidad, durante la evolución de una CME a la cual se le pueden asignar los parámetros cinemáticos manualmente. La segunda carpeta contiene el código desarrollado para simular las CMEs en conjunto, buscando sus puntos de interacción así como el comportamiento de la distribución de densidad y velocidad resultantes. Dentro de cada carpeta encontrará más detalles.
